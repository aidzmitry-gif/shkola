# Школа · Shkola

**Скилл для Codex, который помогает создавать практическое обучение на разные темы:** от программы и уроков до игровых заданий, проверки навыков и работающего учебного интерфейса.

Основан на опыте разработки технической школы по солнечной энергетике. Подход применим к обучению сотрудников, клиентов и специалистов: аудитория → нужное действие → практика → самостоятельная проверка → полезный результат. Формат и объём определяются задачей, а не размером исходной школы.

## Быстрая установка в Codex

Откройте новую задачу в Codex и отправьте:

```text
$skill-installer Установи скилл из https://github.com/aidzmitry-gif/shkola/tree/main/skills/shkola
```

После установки используйте `$shkola` на следующем ходе. Если скилл не появился в списке, перезапустите Codex. Доступность инструментов установки зависит от вашей среды; можно установить файлы вручную.

### Вручную из ZIP

1. Скачайте и распакуйте [готовый скилл ZIP](https://github.com/aidzmitry-gif/shkola/releases/latest/download/shkola.zip).
2. Найдите папку `shkola` и скопируйте её целиком в личную папку скиллов:

   | Система | Куда скопировать |
   | --- | --- |
   | Windows | `%USERPROFILE%\.agents\skills\shkola` |
   | macOS / Linux | `~/.agents/skills/shkola` |

3. Проверьте, что файл лежит непосредственно в `shkola/SKILL.md`, а рядом есть `agents`, `assets` и `references`. Не копируйте только один `SKILL.md`: ему нужны связанные материалы.
4. Откройте новую задачу. Если скилл не обнаружился, перезапустите Codex.

Если скачали архив исходников вместо готового скилла, нужная папка находится внутри `shkola-main/skills/`.

Для одного проекта можно вместо личной папки использовать `<проект>/.agents/skills/shkola`. Если скилл уже установлен, сначала сохраните свои изменения и обновите существующую копию; не создавайте несколько копий с одинаковым именем.

Способ установки и расположение локальных скиллов сверены с [официальной документацией OpenAI](https://learn.chatgpt.com/docs/build-skills). В управляемой среде могут действовать ограничения администратора.

## Как пользоваться

Скопируйте запрос и заполните известное. Если есть существующие материалы, укажите путь или приложите их.

```text
$shkola Создай обучение по [теме] для [аудитории].
После обучения человек должен уметь [наблюдаемое действие].
Начальные знания: [что уже умеет].
Нужный результат: [программа / полные уроки / обучение на существующем сайте].
Материалы и ограничения: [что есть и что важно].
Нужны [практика / игровые ситуации / проверка навыков].
Коммерческая цель, если есть: [какой добровольный следующий шаг уместен].
```

Например:

```text
$shkola Подготовь законченный урок для новых менеджеров:
как рассчитывать количество упаковок по заказу.
Нужны пример, тренировка, самостоятельная задача и новый вариант
после раскрытия ответа. Формат — текст, без сайта и продаж.
```

```text
$shkola Улучши нашу школу из 18 уроков по уходу за садом.
Сохрани аудиторию владельцев и весь согласованный охват.
Добавь практику и игровые ситуации. После полезного результата
можно предложить наши наборы для полива, если они человеку нужны.
Материалы: [путь]. Сделай изменения в существующем проекте.
```

```text
$shkola Создай техническое обучение для продавцов оборудования.
Ученик должен собирать исходные данные, сравнивать решения
и распознавать случаи, где данных недостаточно.
Сначала проверь один полный учебный сценарий,
затем выполни весь согласованный объём.
```

## Что включено

- [Порядок работы](skills/shkola/SKILL.md): восстановить задачу, определить навыки, проверить образец, создать согласованный объём и принять результат.
- [Шаблон паспорта](skills/shkola/assets/course-passport.md): аудитория, навыки, практика, проверка, границы и пилот.
- [Проектирование уроков](skills/shkola/references/course-design.md): решаемые задания, обратная связь, равноценные варианты, рубрики и критичные ошибки.
- [Игры и предложения](skills/shkola/references/engagement-and-offers.md): решения с последствиями, знаки освоенных умений и добровольный коммерческий маршрут.
- [Реализация и приёмка](skills/shkola/references/delivery-and-evaluation.md): реальный путь ученика, хранение, экспорт, доступность и достаточные свидетельства.
- [Методические основания](skills/shkola/references/learning-evidence.md): первичные публикации и границы выводов.
- [Разбор разработки](skills/shkola/references/solar-retrospective.md): удачные решения, ошибки и изменения процесса.

Для самого скилла не нужны собственный сервер, API-ключи или база данных. Он использует возможности вашей среды Codex. Если результатом должен быть сайт, применяет существующий стек и доступные инструменты проекта.

## Что уже проверено

Исходный скилл прошёл проверку структуры и два авторских прогона на других темах: расчёт коробок для менеджеров и улучшение школы садоводства. Порядок масштабирования уточнён и повторно проверен. Пример первого результата включён в этот репозиторий.

Эти проверки подтверждают применимость к протестированным запросам. Рост навыков реальных учеников, продаж и экономия времени требуют отдельного пилота и сопоставимых измерений. Скилл не задаёт обязательные 95 уроков, порог 75% или единственный график повторения для всех тем.
